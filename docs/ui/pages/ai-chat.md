# AI 对话页 (AI Chat Interface)

## Purpose
核心对话界面。用户与选定的 AI 角色进行实时交互，支持流式响应、代码高亮和上下文记忆。

## Navigation
- **From:** AI 角色广场, 侧边栏历史记录
- **To:** AI 角色广场 (返回)

## Elements
- **Header:**
  - 当前角色信息 (头像 + 名称)
  - 更多操作 (三个点): 清空上下文, 删除会话,查看角色详情
  - 移动端: 汉堡菜单 (唤起侧边栏)

- **消息列表 (Message List):**
  - **AI 消息气泡:**
    - 左侧显示
    - 角色头像
    - 消息内容 (Markdown 渲染, 代码块高亮)
    - 底部操作栏: 复制, 重新生成, 点赞/点踩
  - **用户消息气泡:**
    - 右侧显示
    - Primary Gradient 背景
    - 文本内容
  - **Typing Indicator:** AI 正在思考时的动画

- **输入区域 (Input Area):**
  - 底部固定
  - **输入框 (Textarea):** 自动增高
  - **发送按钮:** 输入时高亮，发送中变为"停止"图标
  - 辅助按钮: 清空 (可选)
  - Footer 信息: "AI 生成内容可能不准确"

## States
- **Default:** 展示历史消息，滚动到底部。
- **Streaming:** AI 回复时打字机效果，自动滚动跟随。
- **Loading (Initial):** 加载历史记录骨架屏。
- **Empty:** 新会话，显示角色欢迎语和预设 Prompt 建议。
- **Error:** 消息发送失败提示 (红色叹号)，支持重试。

## Design Style
- 沉浸式体验，去除不必要的边框。
- 消息气泡区分度高 (不同背景色)。
- 输入框要有明显的 Focus 状态。
